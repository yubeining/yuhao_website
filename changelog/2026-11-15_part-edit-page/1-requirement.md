# 需求 —— 编辑零件页的五处优化（2026-11-15）

> 需求原话：「为什么 ← 测试1 …订单提交前，每个零件至少要有一份图纸 你先给我方案」→ 确认全做。

## 问题

1. 返回链接显示的是**订单标题**（`← 测试1`），没有"返回"二字，用户不知道点了去哪。
2. 图纸说明是**静态文字**：图纸已经传了还在提示「订单提交前至少一份」，误导。
3. 图号在表单里重复出现（标题下已有版本），且只读文本没有"不可修改"的信号。
4. 「保存修改」**永远可点**，没有改动也能提交一次空请求。
5. 有未保存改动时点返回，**直接丢输入**，没有确认。

## 验收

- 返回链接文案 `← 返回订单`，订单名进 `title`
- 标题副行 `图号 · 第 N 版`；编辑态表单里不再有图号字段
- 图纸状态行随事实变化：`已上传 N 个文件` / `待上传 N 个文件` / `未上传 · 订单提交前需上传`
- 无改动时「保存修改」禁用
- 有改动时点返回弹确认
