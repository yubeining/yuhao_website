# 需求 —— 能远程看线上日志（2026-11-14）

## 需求原话

> 「有没有办法把日志给打到一个服务/接口 这个服务能读取所有日志」
> 背景：排查「注册验证码收不到」时，每次都要人工进 pod grep，再由人贴回来。

## 现状

- 应用日志只写 stdout，容器里没有文件可翻
- 线上跑在 Sealos「应用管理」的 pod 里，看日志要进 Sealos 控制台
- 没有 kubeconfig 落在开发机上，所以外部无法 `kubectl logs`

## 必须满足

- 能从公网 HTTP 读到**最近**的日志，按关键字过滤
- 默认关闭：不配置就当作不存在
- 不能因为开了这个口子把日志变成公开资源

## 验收

- 未配置 token：`/actuator/logtail` 返回 404
- token 错误：401
- token 正确：200，返回最近 N 行，可用 `q=` 过滤
- 不影响现有接口与部署健康检查
