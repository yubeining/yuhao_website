# 需求 —— 运营报价页去掉多余信息（2026-11-15）

> 需求原话：「运营侧 你这个处理报价页面很乱 … 我不需要多余的信息」
> 决策：① 保留「对客单价」列；② **不做汇率试算**（不显示汇率、不要试算按钮）。

## 现状乱在哪

| 问题 | 具体 |
|---|---|
| 两张卡讲同一件事 | 「订单信息」卡的客户/零件数/期望交期，标题和表格里已有 |
| 加成率占一整卡 | 一个数字 + 保存，配「当前/最后修改」两列和 80 字规则说明 |
| 图纸列塞文件名 | 长文件名把表格撑开，实际动作只是看图 |
| 预览两列平时是空的 | 不点试算就是两个破折号 |
| 底部堆一起 | 币种、交期、试算、发出、提示文字挤一行 |
| 历史报价 0 版也占一张卡 | 空状态占位 |

## 验收

- 订单上下文压成标题下一行
- 加成率/币种/交期并到表格底部的设置行
- 图纸改成「查看」，去掉文件名
- 去掉「对客小计」列与试算按钮、试算说明
- 历史报价为 0 时不渲染整卡
