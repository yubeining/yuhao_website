# 需求 —— 下线供应商邀请入口与页面（2026-11-14）

## 需求原话

> 「这边UI要做修改 目前没有 收到供应商邀请？从邀请链接入驻 这一个 需要去掉 以及对应的页面 如图2 这是假的」

截图 2 是直接访问 `/auth/invite`（无 `token`）时的「没有有效的邀请」状态。

## 核实（动手前）

- 这个页面**不是假的**：`InvitePage` 调的是真后端
  （`GET /api/v1/auth/supplier-invites/{token}`、`POST .../register`），
  带 `?token=` 打开就是真的供应商注册表单。截图状态只是因为没带 token。
- 运营端 `/ops/onboarding` 生成的邀请链接，落地页正是它。

## 决策

给出三个选项后，需求方选择：**入口和页面都删，运营端「发邀请」也一并下线**。
后端接口暂时保留（不在本次范围内）。

## 验收

- 登录页不再出现「收到供应商邀请？从邀请链接入驻」
- `/auth/invite`、`/ops/onboarding` 不再有路由；运营侧导航不再有「供应商入驻」
- `npm run type-check`、`npm run build` 通过
