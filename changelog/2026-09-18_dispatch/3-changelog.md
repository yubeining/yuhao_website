## 4b 组生产订单、派单、接单（2026-09-18）

### 改了什么

- **迁移** `2026-09-18_02_dispatch.sql`：`ops_order` 加状态（组装中 / 定向派出 / 挂全市场 / 已被接下）、派法、派单轮次、对供交期、派出时间；
  新表 `ops_order_offer`（按 生产订单 + 轮次 + 供应商 唯一）；`supplier_order` 加生产订单、状态、对供交期快照、接单 / 取消时间、取消原因，
  部分唯一索引「每张生产订单最多一张已接单」；新表 `supplier_price_line`（报价域，接单时的对供价快照）；审计上下文加 `OPS_ORDER` / `SUPPLIER_ORDER`
- **订单域**：`DispatchService`（派单池、建 / 删生产订单、拆行、撤回分配、定向派、挂市场、收回、收回供应商）、`SupplierOfferService`（看单、接单、拒接、我的订单、退单、两种上下文看图）、

  对外契约 `OrderDispatching` + 同步事件 `SupplierOrderAccepted`
- **报价域**：`SupplierPricingService`（运营看各家对供价、供应商看自己的价、接单事件里写快照 —— 写不成整体回滚）、`PriceCalculator.supplierUnitPrice`
- **接口**：运营 `/ops/dispatch/pool`、`/ops/dispatch/allocate`、`/ops/dispatch/unallocate`、`/ops/ops-orders`（列表 / 新建 / 详情 / 删除 / offer / publish / recall / revoke-supplier / supplier-prices）；

  供应商「订单市场」「单子详情」（接 / 不接、看图）、「我的订单」（价格快照、退单、看图）；「我抢到的」并进「我的订单」。这几页去掉原型横幅，原型假逻辑删掉

### 推导（不是给定的）

- 对供单价取整沿用对客价：2 位四舍五入，小计 = 单价 × 数量

- 供应商接一张「这一轮给过他、现在已经没了」的单回 409；从来不是给他的回 404（不暴露存在）
- 本轮不做生产订单取消（会破坏「一次拆完」），用「撤回分配」+「删除空单」代替

## 第 5 步 合同 + 签字（2026-09-20）

需求方 2026-09-20 定：**合同先只做交互和签字，不做 PDF，但流程要有**；**7 天不签算超时，从供应商接单算**；签字前双方仍可退。

### 改了什么

- **迁移** `2026-09-20_01_contract.sql`：`supplier_order` 加建合同 / 签字的时间戳和操作人；状态加 `CONTRACT_PENDING` / `CONTRACTED`；
  取消原因加 `SIGN_TIMEOUT`；CHECK 钉住「待签必须有建合同时间、已签必须有签字时间和签字人」；
  「每张生产订单同时最多一张在手的供应商订单」从「只算已接」扩到「已接 / 待签 / 已签」；超时扫描的索引。
  **没有新表** —— 合同眼下没有自己的内容字段，就是单据上的几个时间戳；等条款 / 附件定了再拆成合同域（文档 12 §4 已记）
- **后端**：`POST /ops/supplier-orders/{id}/contract`（建合同）、`DELETE`（作废重建）、`POST /supplier/orders/{id}/sign`（签字 = 锁定）；
  `SignDeadline`（接单 + 7 天，配置项 `app.dispatch.sign-timeout-days`，**这是业务规则不是工程取值**）；
  `SignTimeoutJob`（每小时扫一次，Redis 锁 + fence，按 CLAUDE.md §8；一张一个事务，先锁生产订单再改）；
  退单 / 收回在签字后一律 409 `dispatch.contract_signed`
- **前端**：运营生产订单详情里「建合同 / 作废合同」和签字期限、签字时间；供应商「我的订单」里的「签字确认」、期限提示、签字后只读。
  顺手修了一个自己写出来的 bug：供应商订单进入待签 / 已签之后图纸不显示了（条件写成了只在「已接单」时显示）——
  签完才是最需要图纸的时候
