# 需求 —— 第 4 步：供应商入驻 → 组生产订单 → 派单 → 供应商接单

> 2026-09-18

## 背景

第 3 步之后客户能确认报价，但确认之后没有下文：线上没有供应商账号，运营端派单、供应商端接单都是原型页（数据已清空）。

## 需求方当面拍板（2026-09-18，全部记在设计文档 11 / 13）

| 问题 | 定的 |
|---|---|
| 本轮范围 | 做到供应商接单为止；合同 / 签字放下一轮 |
| 对供折率 | 填 0.8 = 乘 0.8 |
| 供应商何时能看图 | 派到他就能看，每次看落审计 |
| 定向派给几家、一家拒接 | 只把他移出，其余照常可接；全部拒接才回运营待派 |
| 对供交期 | 运营每次派单时手填 |
| 供应商账号 | 只能运营邀请；链接 7 天有效、用一次失效、可作废 |
| 注册填什么 | 只填公司名 + 联系人 + 邮箱 + 密码 |
| 何时能派单给他 | 运营录好折率就能派 |
| 能力库 | 自由文本，系统不判断匹配 |
| 供应商接单前看得到 | 零件名称 + 图号、材料 + 表面处理、数量 + 对供单价 + 小计、交期 |
| 拆行 | 一次拆完：拆的时候各份之和 = 该行数量 |

之前已定、本步沿用：两种派法运营每单二选一（文档 12 §3）；一张生产订单可装多个客户单的零件（D13）；签字前双方可退（文档 12 §4）；没人接不兜底（Q13）。

## 验收

- 4a：运营发邀请 → 供应商凭链接注册 → 登录供应商端；过期 / 用过 / 作废的链接进不来；运营录折率后这家变成「可派单」
