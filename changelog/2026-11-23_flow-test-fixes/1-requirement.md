# 线上流程测试发现的问题 —— 需求

## 原话

- 「测试中发生的问题 你都修复一下」
- 确认框：「报完工, 开工, 建合同」三个都加。
- 语言：「没存就跟浏览器」。

## 背景

2026-11-23 在线上把 测试2 从客户确认报价一路点到质检合格，过程中发现：

1. 运营选对供交期时，日期选择器的弹层在矮窗口里被裁掉下半截，点不到日期。
2. 供应商点「开工」「完工」、运营点「建合同」都是一下就生效，没有确认框。
   开工 / 完工没有撤回功能；建合同在签字前可以作废。
3. 邀请注册的测试供应商界面是英文：账号没存语言时，后端在登录响应和 access token 里都兜底成 `en`，
   前端把账号语言排在浏览器语言前面，所以没设语言的人一律看英文。

## 验收

- 日期弹层：下方放不下就翻到上方；上下都放不下时整张日历仍在视口内。
- 三个按钮点了先弹确认框，取消则什么都不发生。
- 账号没存语言：登录响应 `locale` 为 null，token 不带 `locale`，页面按浏览器语言显示；
  存了语言的账号行为不变。

## 不在范围内

- 发货给客户：系统里还没有这一步（客户订单停在 READY），是新功能，要先定流程。
- 质检输入框的底纹：C6 只管搜索框。
- 线上测试数据清理：等本人点头。
