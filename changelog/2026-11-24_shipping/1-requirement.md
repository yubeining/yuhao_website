# 发货：运营发给客户 + 随货文件 + 确认收货 + 供应商运单号 —— 需求

## 背景
2026-11-24 在线上用真实账号把一张演示单从下单走到质检完工，订单停在「已完工 · 待发货」：
运营没有发货的入口，客户看不到物流信息，供应商「发给平台」也不填任何东西。
设计文档 12 §2 早已定了 `READY --SHIP--> SHIPPED --CONFIRM_RECEIPT--> COMPLETED`，标注「发给客户下一轮做」。

## 需求方当面定的（2026-11-24）
| 问题 | 定的 |
|---|---|
| 运营发货要填什么 | 承运商 + 运单号，都必填；承运商**自由填写**（三方运输公司还没定） |
| 质检报告 / 材质证明 | **运营手动上传文件** |
| 随货文件是否必传 | **可选**，不拦发货 |
| 随货文件分不分类 | **不分类** |
| 格式 | **PDF、JPG、PNG** |
| 发货后能否补传 | **能**（客户确认收货前） |
| 客户一直不确认收货 | 先不管 |
| 物流跟踪 | 先不查 |
| 确认收货（文档 12 已定） | 这次一起做 |
| 供应商发给平台 | 承运商 + 运单号必填；**每次发货一条记录**（返工后会再发） |
| 运营「已收到货」动作 | 待定，本次不做 |
| 供应商发货件数 | 暂时不填 |

## 验收
- 只有「已完工 · 待发货」的单能发；发完变「已发货」，客户看得到承运商、运单号、发货时间和随货文件。
- 客户点「确认收货」后订单「已完成」，之后不能再传随货文件。
- 随货文件每次签发下载链接都落审计；别家客户拿不到。
- 供应商发给平台必须填承运商和运单号；返工再发，两批单号都留着。
