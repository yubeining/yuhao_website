# 需求 —— 主流程 E2E + 修掉它抓到的两个问题（2026-11-12）

## 需求原话

> 「我需要你跑 e2e 通过 computer use 的方法 把整个主流程都走一遍 确保能走通」
> 「可以 然后你修复那几个问题」

## 环境

- 本机没有 computer-use 工具，改用 **Playwright 驱动本机 Chrome**（`playwright-core` + `channel: 'chrome'`），
  不下载浏览器；效果等价：真实渲染、真实点击、真实上传。
- 独立库 `mfg_e2e`，不碰开发库 `mfg`。
- 存储用 `provider=memory`（本地不需要对象存储）。

## 主流程（22 步）

```
客户   注册 → 登录 → 建订单 → 录零件 + 传图纸 → 提交
运营   登录 → 加成率 → 原价/币种/交期 → 试算 → 发出报价
客户   确认报价（价格锁定）
运营   新建生产订单 → 分配零件 → 生成供应商邀请链接
供应商 凭邀请注册
运营   录折率 → 挂全市场派单 → 建合同
供应商 接单 → 签合同 → 开工 → 完工 → 发给平台
运营   质检（合格/返工/报废 按件数）
账号   账号管理页：新建外部用户 → 禁用 → 启用
```

断言用页面上的事实（"已提交""已挂全市场""已全部合格"），不是"点到了按钮"。
