# 需求：按原型 v2 重写全部前端

## 用户原话

> 我需要你把原型v2.html 移动到这个项目中来 所有的前端原型设计按照这个html 重写

## 背景

`原型v2.html` 一直放在仓库外面（桌面上），是一个 2291 行的单文件 vanilla JS 原型，
包含完整的设计系统（590 行 CSS，token 化、明暗双色）、约 30 个界面、
一套内存数据仓，以及从询价到结算的完整状态流转。

而 `portal/` 里只有 3 个占位页（`CustomerRfqsPage` / `SupplierQuotesPage` /
`OpsDashboardPage`），加起来 820 行，全是探针，没有任何业务界面。

两边完全脱节：原型是设计的真源但在仓库外，仓库里的前端没有设计。

## 动手前确认的两件事

问了用户，得到明确回答：

1. **数据层**：移植内存数据仓，保持可点。
   （备选是「静态界面，数据写死」和「直接对接后端」，都被否决 ——
   后端 `domain/` 下 14 个业务包全是空的，没有任何接口可调。）

2. **界面状态**：拆成真实路由。
   （备选是照搬原型的单页状态机 `R = {screen, tab, area, sel}`，
   被否决的理由是它违反 CLAUDE.md §2 的「路径前缀即受众」，
   而且刷新就回登录页。）

## 验收标准

- 原型文件进仓库
- 三端（客户 / 供应商 / 内部）全部界面按原型重写，视觉与原型一致
- 每个界面有自己的 URL，可刷新、可直接访问、可发链接
- 询价 → 报价 → 接受 → 拆包 → 抢单 → 签约 → 上报 → 交付 → 回款 → 开票
  整条链路可以在界面上真实走通
- `npm run type-check` 与 `npm run build` 通过
- 后端托管下深链接不 404
