# 需求 —— 图纸在线预览 + 附件区改版（2026-11-15）

> 需求原话：「然后图纸上传完了也不能预览 这个功能也要有 而且这边的UI也很丑 看看怎么优化」→ 选方案 A。

## 现状问题

- 附件用 chip（flex wrap）堆叠：`下载` 按钮被挤成两行、文件名截断且无 tooltip、`×` 太小
- 没有预览能力，只能下载
- 上传中的进度条与已完成的文件样式完全两套

## 格式能力边界（决定方案）

| 格式 | 浏览器能否原生渲染 |
|---|---|
| PDF / PNG / JPG / WEBP / GIF | 能 → 应用内弹层预览 |
| STEP / IGES / DWG / DXF / SLDPRT | 不能 → 只给下载，预览按钮置灰并说明原因 |

## 验收

- 文件列表为行式：类型徽标 / 文件名（截断 + tooltip）/ 大小 / 预览 / 下载 / 删除
- PDF、图片点「预览」在应用内弹层显示；Esc 与点击遮罩可关闭
- STEP 等格式「预览」置灰，hover 说明「该格式无法在线预览，请下载后用 CAD 软件打开」
- 下载用带 `Content-Disposition: attachment` 的 URL，预览用 inline URL，两者分开
