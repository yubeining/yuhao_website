## 补充（同日）：改成「查看 / 编辑」两态

需求原话：「应该是有编辑按钮 编辑完点击确认 然后保存」。

- **查看态**：字段用「标签 + 值」的文字行展示，卡片右上角一个「编辑」
- **编辑态**：昵称变输入框并自动聚焦，邮箱 / 身份 / 注册时间保持灰色禁用，
  底部「取消 / 保存」；「编辑」按钮隐藏
- 「保存」在没改动时置灰；保存中显示 `…` 并禁用
- 保存成功回查看态，卡片内显示「已保存」，2 秒后自动消失；顶栏昵称同步
- 「取消」丢弃改动直接回查看态，不弹确认（只有一个字段，弹窗更烦）

为什么不再用灰色输入框表达查看态：一排灰框看起来像「本来能改但被禁用」，
而只读字段就是文字。

验证：Playwright 实跑 —— 查看态输入框 0 个、编辑按钮 1 个；编辑态 3 个禁用字段、
保存初始为禁用；改昵称保存后顶栏同步、回到查看态、「已保存」出现。
