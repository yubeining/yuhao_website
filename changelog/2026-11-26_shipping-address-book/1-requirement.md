# 收货地址簿

## 原话

> 需要修改一个需求 现在的地址的设置 需要放在用户设置那一边 参考淘宝 而不是在用户每次创建订单的时候都要填写

设计稿：https://claude.ai/artifact/P7Zj6Sj6yS7jVPjdAo34nv（v2：订单页按钮文字改为「编辑」）

## 背景

现在地址只存在订单上（`customer_order.ship_to_*` 9 列，2026-11-23 加），每张订单在详情页手填一次。

## 需求方已定（2026-11-26）

| # | 问题 | 定的 |
|---|---|---|
| Q1 | 字段 | 照现有 9 个：国家、收货公司、收货人、电话、地址、地址第二行、城市、州/省、邮编；必填同现在 |
| Q2 | 归属 | 按个人账号，同事之间互不可见 |
| Q3 | 下单带出 | 建草稿时自动填默认地址 |
| Q4 | 订单上存什么 | 只存快照（现有 9 列），不存地址簿 id |
| Q5 | 订单上改地址 | READY 之前可以「编辑」，方式是从地址簿换一条；不再在订单上手填 |
| Q6 | 存量订单地址 | 不导入地址簿 |
| Q7 | 搬淘宝哪些功能 | 智能粘贴、复制。不要标签、地图、置顶、批量删、搜索 |
| Q8 | 默认地址 | 第一条自动成为默认；删掉默认后，剩下最早加的那条顶上 |
| Q9 | 条数上限 | 需求方说「你看着办」，方案里定 |
| Q10 | 运营 | 可以看（只读） |
| Q11 | 入口 | 账号设置页里一张卡片 |

## 验收

- 设置页能增、删、改地址，能设默认；第一条自动默认；删默认后最早一条顶上。
- 新建草稿自动带上默认地址；没有地址簿时订单卡片提示新增。
- 订单页「编辑」从地址簿换地址，READY 后只读；改 / 删地址簿不影响已有订单。
- 智能粘贴、复制可用。
- 运营能看某个客户用户的地址簿，不能改。供应商端看不到。
