# 实施计划 —— 国家改存 ISO 两位代码（2026-11-14）

## 方案

1. 新增 `portal/src/i18n/countries.ts`：249 个 ISO 代码 + `countryName(code, lang)`
2. 新增 `portal/src/components/CountrySelect.tsx`：值为代码，显示名按当前语言生成
3. 注册页改用 `CountrySelect`，提交两位代码
4. 运营端「账号管理 → 组织」的国家字段从自由输入改成同一个下拉，列表按本地化名称显示

## 关键取舍

- **显示名用 `Intl.DisplayNames`，不写 500 条翻译**：浏览器原生支持，切语言自动跟随，
  加语言时不用维护第二份国家名清单。代价是依赖运行环境（现代浏览器均支持）。
- **按显示名排序，不按代码**：中文界面下按拼音，「奥地利」不会因为代码 `AT` 被排到最前。
- **「其他」不落库**：`OTHER` 只是下拉里的哨兵值，提交前转 `null`，
  因此后端 `@Size(max = 2)` 不用改。

## 被否决的方案

- **存英文全名、放宽后端到 `@Size(max = 200)`**：与运营端现有口径冲突，
  且国家名多语言时无法翻译（库里是写死的英文）。
- **只补欧洲 40 国**：需求方要全球。
- **自建国家中文名映射表**：500 条静态数据，加语言就要重写，收益不如原生 API。
