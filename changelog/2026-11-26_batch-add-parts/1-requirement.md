# 需求：客户批量添加零件 / 图纸

## 原话
> 需要开发一个功能 客户这边可以批量的添加图纸 也就是上传一个/一堆文件可以解析并转成我们的格式

## 逐条拍板（2026-11-26）
- 输入：一堆图纸 / Excel 清单 + 图纸 / 压缩包都支持；也能不导入、手动一行行加（「和单个添加一样」）。
- 文件变零件：同一批里同图号的文件合成一行；认不出图号的文件一个一行；一个文件里多个零件不做。
- 字段：图号、名称、数量、客户版本从清单列 / 文件名取；材料、表面处理客户自己填，不用 AI、不外发图纸。
- 确认：入单前客户逐条确认；列表和订单零件表同列，空格显示「—」，不写「必填 / 待补」；点行弹框改，文件能删能加。
- 识别不全：照样建行。图号 / 名称 / 数量没填全的行不能保存（这三项现有明细行就必填）；材料、表面处理保持选填。
- 上限：单个文件 20MB；压缩包本身不限，只限解开后的每个文件；批量不设上限。
- 「图号重复就不要去重了 这个不限制唯一」—— 全站都改，取代 D16。
- 保存前服务端不存任何东西（「解析出来变成草稿保存或者提交才落库」），例外是将来需要 AI / 其他服务解析时。
- 保存走新的批量接口，一个事务；之后逐个传图纸，失败的行显示缺图纸可补传。
- Excel 列按表头自动猜、客户可改，不记忆；表头先只认「序号 / 图号 / 名称 / 数量」；.xlsx / .xls / .csv 都支持；原件不存。
- 清单里两行同图号：各算一行，图纸每行都挂一份。
- 删唯一索引的迁移这次一起上，接受回滚风险；一个分支一起做；新依赖（Excel 库、zip 库、vitest）同意。

## 验收
- 草稿订单零件卡有「批量添加」；导入后按上述规则出列表，能改、能删、能手动加，保存后订单里出现对应行和图纸。
- 同一图号再加一次是新零件。

# 第二轮（2026-11-27）：改成订单详情页整页编辑

## 原话
> 无论是单行还是多行 你必须再点进去那个页面添加零件 批量添加也是 …… 可以同时支持添加一个或者多个 但是你这个交互有点冗余

> 我不要弹框 我就是在这个页面添加零件 统一保存

> 取消的意思是取消本次的编辑 这个订单还未发布的话 已经保存的这些零件 还是可以继续修改的

> 订单信息和收货地址也要考虑 编辑 再保存 但是这样也都很冗余 反正一个订单最后只能保存一次

> 你这个草稿状态填不填都没有关系 也不需要提示他填这些信息 但是提交订单的时候弹框拦截要他填信息

## 逐条拍板（2026-11-27，按 mock 页面逐轮确认）
- 不再有单独的「添加零件」页和「批量添加」页，就在订单页的零件表里加、改、删。
- 整页一个「编辑」一个「保存」：零件、订单信息、收货地址一起编辑一起保存；底部固定栏「取消 / 保存」。
  「取消」= 撤销这一轮全部改动（按钮叫「取消」，不叫「放弃」）。
- 已保存的零件平时只读，点「编辑」后才能改；删行、删文件、加文件都等保存才生效。
- 不要零件页了：点文件名直接预览。表格加「表面处理」列。文件在行下展开，能删能加，加文件按钮只要「＋」。
- 新建订单直接进编辑状态；第一次保存才建单，取消回列表不留空单。
- 草稿随便存，不提示必填（删「请先填期望交货日期」、缺图纸黄条、交期红星）。提交时弹框只列缺的项目（项目 + 红字状态），
  「去完善」进编辑状态、缺的地方标红、滚到第一处。公司名称也算一项，「去完善」跳设置页。
- 收货地址只显示一条（新单自动带默认地址）。编辑时「修改」= 只改这个订单的地址，不同步地址簿；「更换」= 从地址簿选。
  地址簿为空时直接添加：调研京东 / 淘宝的做法后定为「照京东」—— 存进地址簿（设为默认）并用在这一单。
  提交以后、就绪之前，地址卡片单独「修改 / 更换」，立即生效。
- 草稿里图号 / 名称 / 数量的库列放开非空，提交时后端检查。
- 保存时图纸上传失败：留在编辑状态，失败文件标红，可以再点保存重传或删掉。
- 两人同时编辑：后保存的覆盖，不做冲突检测。
- 手机：表格横向滑动，不做卡片布局。
- 订单列表副标题「录入零件、传好图纸后提交」删掉。
- 迁移和代码一起发，接受回滚风险；旧的逐行 / 批量 / 改行 / 删行 / 开新版本 / 单改名称交期接口一起删；继续在本分支做。

## 验收
- 订单页点「编辑」能在表格里直接改已保存的零件、加行、导入文件 / 文件夹 / 压缩包 / 清单、删行、在行下加删图纸；
  「保存」一次存进去，「取消」全部撤销；编辑中离开页面会提醒。
- 新建订单进去就能填，保存后才出现在列表里；不保存就走不留空单。
- 草稿里不出现任何必填提示；点「提交订单」缺什么列什么，「去完善」把缺的地方标红。
