# 变更记录

## 实际改动
- 外壳：删除顶栏；侧栏 224px、sticky 满高，顶部品牌 + 端标识（客户 / 运营）或大区分段切换（供应商），中间导航可独立滚动，底部「设置」+ 用户菜单（向上展开）。
- 窄屏（≤900px）：侧栏变为顶部横条，导航只留图标，用户菜单向下展开。
- 供应商订单市场页现在也有侧栏（无导航项，只有品牌、大区切换、设置、用户菜单）。
- 账号资料缺失提示条（`.appnotice`）从整屏横幅改为主区顶部的提示块，颜色改走 warn token（之前写死浅色值，深色主题下发亮）。
- 设置页外观选项里的小预览色块同步成新配色。
- 字体：IBM Plex Sans / Mono（latin 400/500/600、mono 400/500），中文仍落系统字体。
- 客户订单详情：零件表置顶，订单信息 + 收货地址并排在下。

## 验证
- `npm run build` 退出码 0。
- 客户端（本地 Tester 账号）订单列表、订单详情在浅色 / 深色 / 390px 下截图检查，用户菜单展开正常。

- 登录 / 注册 / 入驻页只随 token 变化（左侧品牌栏变石墨色），没有逐页截图。
