# Portal 整体 UI 改版 —— 需求

## 原话
「我需要你找一下专业的网页UI UX的设计 符合我这个项目的 可以做全部大改 因为这个页面看起来还是太丑了 也不够简洁大气」

## 过程
1. 出了参考调研 + 三个方向对比页（A 纯净 / B 明亮专业 / C 工业精密），用本地测试客户的两单真实数据渲染。
2. 需求方选 **C · 工业精密（Xometry / Fictiv 路线）**，并定了四项：
   - 主动作色**保留品牌蓝**，不换橙
   - 字体**打包 IBM Plex**（Sans + Mono）
   - `docs/design/prototype/原型v2.html` **不再作设计真源**
   - 客户订单详情页**零件表挪到最上面**
3. 订单市场页（原来通栏无侧栏）也加侧栏 —— 计划里提出，需求方批准。

## 验收
- 三端共用外壳：无顶栏，石墨侧栏承载品牌 / 端标识 / 大区切换 / 导航 / 设置 / 用户菜单
- 浅色、深色、900px 以下窄屏都可用
- 不新增任何没有数据来源的界面内容（C5）
