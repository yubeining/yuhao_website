# 需求 —— 第 2 步：客户订单（草稿 → 加零件 → 提交）+ 接客户端界面

> 2026-09-14 ｜ 设计文档 11 §4 第 2 步

## 背景

第 1 步只做了零件图纸的后端，客户在浏览器里什么都做不了：客户端订单页全跑在假数据上，
而且**用真实账号登录后点「新建订单」会直接报错** —— 真实登录不会写假数据里的「当前公司」，
`mock/actions.ts` 的 `createOrder` 取不到公司就抛异常。

另外评审第 1 步时发现了几处会挡住第 2 步的问题（见 `2-implementation-plan.md` §A），一并修。

## 出处

- D16 原话：「零件是同一种 但是下单的 item id 就是新的了 便于追溯 这个和淘宝一样」
- D17：一张订单表走到底（文档 11 Q17 已拍板）
- 文档 12 §2：客户只能取消草稿（已拍板）
- CLAUDE.md §3 铁律 7：订单行锁定图纸版本 id，不锁父零件

## 当面拍板（2026-09-14）

| 问 | 答 |
|---|---|
| 提交订单前，每个零件行必须有什么 | 图号 + 名称 + 数量 + 至少一份传完且校验通过的图纸 |
| 客户还填哪些 | 材料（自由文本，可选）、表面处理（自由文本，可选）、订单名称、期望交期（仅参考） |
| 图纸版本什么时候锁；同一图号再次下单怎么办 | 提交时锁；再次下单带出上次锁定的图纸，换图就开新版本 |
| 客户订单接真后端后，还在读假数据的页面怎么办 | 客户端全换真数据；首页、报价页没有真数据时显示「暂无」；运营端、供应商端继续用假数据演示 |

## 验收

- `CustomerOrderFlowIT`：建草稿 / 改名称和期望交期 / 新图号自动建零件和第 1 版 / 缺图纸不能提交 /
  空订单不能提交 / 提交锁版本并冻结订单 / 并发提交只成功一次 / 再次下单沿用锁定版本 / 换图纸开新版本 /
  草稿改行删行取消 / 数量必须为正 / 跨客户 404 / 带订单上下文看图记审计 / 对不上的上下文 404 且不落审计
- `PartDrawingFlowIT` 补：按图号查、只返回传完的文件、上传回执带 Content-Type、complete 幂等、并发 complete 不 500、
  已锁版本拒绝改文件、删文件
- 全量 `mvn verify` 通过；前端 `npm run build` 通过
- 部署后线上浏览器走通：建订单 → 加零件 → 传图纸 → 提交
