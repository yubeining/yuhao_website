# 需求 —— 订单详情的零件表列与行距（2026-11-15）

> 需求原话：「这边的零件list 行间距也不太友好 另外 这个状态很奇怪 明明是零件的 却是图纸的
>   图纸已传 和 缺图纸 这个应该不能算状态吧」→ 确认「图纸只显示有无」。

## 问题

1. **同一件事说两遍**：`图纸` 列显示文件数（`1 / —`），`状态` 列又显示 `图纸已传 / 缺图纸`。
2. **「状态」用词错误**：零件的真实状态（进行中 / 已完成 / 报废）只在投产之后存在；
   图纸有无是资料完整度，不是状态。
3. **「缺图纸」提示出现三次**：顶部 banner、卡头 pill、行内列。
4. **行距偏挤**：单元格 `padding: 12px`，表头更小；数字列与文本列基线不齐。

## 验收

- 零件表只有一列「图纸」，显示 `● 已上传` / `● 未上传`
- 草稿阶段没有「状态」列；投产后出现「进度」列
- 行高加大到约 48px，表头与内容对齐
- 「缺图纸」只保留顶部 banner
