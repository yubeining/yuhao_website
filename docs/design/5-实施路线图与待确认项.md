# 5 — 实施路线图与待确认项

## 1. 分期路线

排期的核心原则：**每一期结束都能跑真实生意，后面每一期都是在减少人工，不是在开新业务。**

### Phase 0 — 官网上线（2–3 周）

**目标**：让欧洲客户找得到你、问得到价。**这一期完全不需要平台。**

| 交付 | 说明 |
|---|---|
| 公司官网 | 公司介绍 / 设备与产能 / 工艺能力 / 质量体系与认证 / 案例（脱敏）/ 团队 / 联系我们 |
| 多语言 | EN + DE（`hreflang` 正确配置） |
| SEO 基础 | SSG、sitemap、Schema.org 结构化数据、Core Web Vitals 达标 |
| Request a Quote 表单 | 提交 → 邮件通知 + 落库成 Lead（可以先只发邮件） |
| GDPR | Cookie consent、隐私政策 |

**内容比技术难。**机加工能力页要有真设备照片、真参数（机型/行程/精度/产能）、
真认证扫描件。欧洲采购看的就是这些。别放"各种机加工零件"的图（你们是非标，展示零件既没意义也可能泄密），
**展示能力，不展示产品**。

---

### Phase 1 — 询价闭环（6–8 周）

**目标**：客户能在线提图纸，你们能在线管流程并出报价。**供应商端先不做，继续用微信/邮件。**

| 端 | 交付 |
|---|---|
| 客户端 | 注册（人工审核激活）/ 上传图纸 / 填规格 / 提交 RFQ / 查看报价 / **接受报价** |
| 后台 | Lead 管理 / RFQ 列表与详情 / 技术评审 / 图纸脱敏上传 / 手工录入供应商报价 / 定价计算 / 报价审批 / 发送报价 / 订单生成 |
| 平台 | Party 模型 / 三端认证 / 端级闸门 / 文件直传 / 图纸版本 / 审计 / 邮件通知 |

**这一期必须做完的硬骨头**：
- 报价五道护栏（文档 3 §4）—— **不可延后，因为 D2 决定了报价即合同**
- 定价规则表 + 分解快照
- 图纸访问审计
- 供应商端 DTO 白名单序列化的代码规范（虽然供应商端还没上，规范要先立）

**Phase 1 结束就能跑真实生意了。**

---

### Phase 2 — 供应商上系统（4–6 周）

| 交付 | 说明 |
|---|---|
| 供应商端 | 待报价列表 / 查看图纸（手机 PDF 预览）/ 填报价 / Excel 导入 / 报价历史 |
| 后台 | 寻源包下发 / 多家报价并排对比 / 选择理由记录 / 供应商能力库 |
| 通知 | 微信 / 企业微信通道打通 |
| `cad-worker` | 图纸自动脱敏 + 加水印 + 转 PDF 预览 |

**采纳率是这一期的唯一 KPI**，不是功能数量。设计约束：
- 报价流程不超过 3 步
- 手机端完整可用
- 微信通知，不是站内信
- 支持 Excel 模板导入（他们习惯用 Excel 算成本）
- 图纸在手机上直接看，不用装 CAD 软件

个位数供应商 + 强制使用，可以**先跑一家试点两周**，改完再推全部。

---

### Phase 3 — 订单与生产（5–7 周）

| 交付 | 说明 |
|---|---|
| 订单 | 订单详情 / 订单行 / 状态机 / 变更留痕 |
| 拆单 | 按供应商拆生产订单，支持同一零件拆多家（D3）+ 未分配数量看板 |
| 生产跟踪 | 供应商接单/拒单、进度上报、里程碑、逾期提醒 |
| 客户端 | 订单进度可视化（**只显示阶段，不显示供应商**） |

拆单不变式的三层守护（DB 触发器 + Service 加锁校验 + 并发集成测试）在这一期落地。

---

### Phase 4 — 质检、发货、单据（4–6 周）

| 交付 | 说明 |
|---|---|
| 质检 | 收货登记 / 质检单（挂生产订单明细）/ 合格率 / 不合格标记 / 质检报告上传 |
| 包装发货 | 装箱单 / 箱唛 / 毛净体积重 |
| 物流 | 第三方承运信息录入 / 跟踪号 / 跟踪事件（先手工录，后接 API）|
| 单据 | PI / 装箱单 / 材质证明 / CoC / 报关资料 自动生成 |
| 结算 | 账款状态记录（已开票 / 已收款 / 部分收款），**不收款不清分** |

---

### Phase 5 — 优化（持续）

供应商评分算法 / 定价算法优化 / 经营看板（毛利分析、供应商表现、询价转化率）/
返修退货流程（D6 补齐）/ 物流 API 对接 / 3D 预览。

---

## 2. 团队与节奏建议

| 角色 | 建议 |
|---|---|
| 后端 | 1–2 人。Phase 1 是最重的一期 |
| 前端 | 1–2 人。官网可以外包或用模板，portal 必须自己写 |
| 产品/业务 | **必须有一个懂业务的人全程在**。这个系统的复杂度在业务规则不在技术 |

**别并行开多期。**Phase 1 没跑通真实订单就开 Phase 2，
结果一定是供应商端做出来发现流程假设错了要重做。
